## 📝 COMO USAR ESTE DOCUMENTO

### 1. **Atualizar Status Regularmente**
```markdown
Edite as colunas:
- %: Progresso percentual atual
- Status: Em desenvolvimento / Pausa / Concluído
- Data última atividade (opcional)
```

### 2. **Adicionar Novo Projeto**
```markdown
| # | Nome | Repositório | Domínio | Status | % |
|---|------|-------------|---------|--------|-----|
| [N] | [Nome] | `[repo]` | [domínio] | [Status] | [%] |
```

### 3. **Arquivar Projetos**
Mova projeto de "Ativos" → "Pausa" → "Arquivados" com motivo registrado.

### 4. **Rastrear Sessão de Trabalho**
```markdown
**[Projeto #N - Nome]**
- Session: session_01XXX
- Branch: claude/[projeto]-[hash]
- Objetivo: [descrição]
- Progresso: [X]% → [Y]%
- Data: YYYY-MM-DD
```

### 5. **Versionar com Git**
```bash
git add PROJETOS_PORTFOLIO.md
git commit -m "chore: atualizar status projetos - ZapScript 75%→80%, MyKollect 65%→70%"
git push
```
