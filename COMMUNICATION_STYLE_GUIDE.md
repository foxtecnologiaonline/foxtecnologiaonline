# Communication Style Guide - ZapScript.me

## 📝 Princípios

✅ **Curto** - Máx. 3-4 linhas por parágrafo  
✅ **Objetivo** - Direto ao ponto, sem fluff  
✅ **Acionável** - Diga o quê fazer, não o porquê  
✅ **Scanável** - Bullets, headers, negrito  

---

## 📊 Formatos Rápidos

### Status Updates
```
✓ Métrica: Valor
⚡ Próximo passo: Ação
⚠️ Risk: Problema
```

### Decisions
```
→ Decisão: X vs Y → Escolhemos X
💡 Razão: [1 line]
📅 Deadline: Data
```

### Problems
```
❌ Problema: Descrição curta
💰 Impacto: Quanto custa?
🔧 Solução: O que fazer?
```

### Wins
```
🎯 Métrica: Crescimento
📈 Número: Aumento %
🎉 Implicação: O que significa
```

## 🎯 Quick Reference

### Em respostas:
- **1ª linha:** Resposta direta
- **2-3 linhas:** Por quê / Como
- **Bullets:** Detalhes/opções
- **CTA:** Próximo passo em negrito

```
O ZapScript.me é uma plataforma inovadora que utiliza tecnologia
```

## ✨ Checklist de Clareza

- [ ] Primeira frase = resposta completa?
- [ ] Sem palavras > 15 caracteres (exceto técnicas)?
- [ ] Máx 1 parágrafo = 3-4 linhas?
- [ ] Negrito nos números/deadline?
- [ ] Call-to-action claro?
- [ ] Sem "acho que", "talvez", "poderia"?

---

## 🚀 Aplicar Agora

### Para comunicação com investors:
Respostas de 1-2 parágrafos + bullets + CTA

### Para status interno:
Formato rápido (✓/❌/⚡) + bullets

### Para documentos:
Máx 1 página por tópico, com sumário executivo
