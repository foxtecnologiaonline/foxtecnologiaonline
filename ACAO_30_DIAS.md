# ZapScript.me - Plano de Ação (Próximos 30 Dias)

## 🎯 Objetivo Principal

**VALIDAR:** As pessoas pagariam por ZapScript?

---

## 📅 Week 1 (Days 1-7)

### Dia 1-2: Setup
- [ ] Criar Google Sheet: "User Feedback"
- [ ] Colunas: Name, Email, Use case, "Pagar SIM/NÃO?", Preço ideal, Notes
- [ ] Agendar 6 calls para esta semana (30min cada)

### Dia 3-7: Entrevistas com os 6 Users
**Call duration:** 30 minutos cada

**Script:**
```
Hi [name]! Obrigado por usar ZapScript.

3 perguntas rápidas:

1. Como você está usando? (deixa falar 5min)
2. O que é o maior problema que resolve?
3. Você pagaria $99/mês? Se sim/não, quanto?

Obrigado pelo feedback!
```

**Preenchimento:** Anotar respostas no Sheet

---

## 📋 Week 2 (Days 8-14)

### Day 8-10: Analisar Feedback
- [ ] Ler todas as 6 respostas
- [ ] Encontrar padrões:
  - Qual é o top use case?
  - Quantos pagam SIM?
  - Preço ideal: $50? $99? $199?
  - Qual é a dor principal?

**Output:** 1 página síntese com 3-5 insights principais

### Day 11-14: Criar Landing Page
**Usar:** Webflow, Carrd, ou até Google Sites (não importa design)

**Conteúdo mínimo:**
```
[Headline]
"Economize 10h/semana em Transcrição"

[Subheading]
Envie áudio no WhatsApp. Receba texto + resumo em 2 minutos.

[3 bullet points]
- Automático (sem copiar/colar)
- Privado (teus dados são teus)
- Rápido (2 min vs 30min)

[CTA]
"Teste grátis por 2 semanas"
[Email input]

[Social Proof]
"6 usuários já estão usando"
```

---

## 🎯 Week 3 (Days 15-21)

### Day 15-17: Outreach via LinkedIn
**Alvo:** 100 agências de marketing (tamanho: 5-50 pessoas)

**Search:** LinkedIn → "agência de marketing" "São Paulo" OR "Rio de Janeiro" OR "Belo Horizonte"

**Message (50 words):**
```
Oi [name],

Estou testando uma ferramenta que economiza ~5h/semana em transcrição de áudio.

Interesse em testar 2 semanas grátis?

Feedback depois de 2 semanas?

[Landing page link]

Abs,
[Your name]
```

**Target:** 50 messages/day × 2 days = 100 total

**Expected response:** 5-10% = 5-10 trials

### Day 18-21: Follow-up
- [ ] Check: Quantas clicaram no link?
- [ ] Check: Quantas criaram conta?
- [ ] Respond: Qualquer pergunta de trial users

---

## 📊 Week 4 (Days 22-30)

### Day 22-25: Collect Data
**Track:**
- Total link clicks (from landing page analytics)
- Total signups
- Who is using trial?
- Feedback so far?

**Email trial users:**
```
"Você está usando ZapScript? Feedback?"

Responda 3 perguntas:
1. Está ajudando?
2. Pagaria $99/mês?
3. Quanto pagaria?
```

### Day 26-30: Analyze & Decide

**Data to collect:**
- Of 100 outreach → X trials
- Of X trials → Y actives
- Of Y actives → Z willing to pay

**Decision matrix:**

```
IF (Z >= 3) → "Continue crescendo"
   Actions: Implement Stripe, start charging $99
   
ELSE IF (2 == Z) → "Maybe later"
   Actions: Refine product, test different nicho
   
ELSE (Z < 2) → "Probably not PMF"
   Actions: Rethink problem or pivot
```
